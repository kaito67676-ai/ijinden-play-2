# イジンデン一人回し（デッキ構築 & ソロプレイ卓上アシスタント）

ブースター第1〜6弾、576枚のカードデータを内蔵した、非公式のファンメイド Web アプリです。
ビルド不要・サーバー不要で、ブラウザだけで動作します。

## 画面について

ヘッダー（デッキ構築／ソロプレイの切り替え）は、ソロプレイ中は隠れています。画面右上の小さな ▽ に触れると出てきます。1画面に収めるため、ヘッダーにはタブ以外を置いていません。

## 使い方（すぐ試す）

`index.html` をダブルクリックしてブラウザで開くだけで動作します。

## 配布・公開する場合

このフォルダ一式（index.html / style.css / app.js / cards-data.js）を、
GitHub Pages・Netlify・Vercel などの静的サイトホスティングにそのままアップロードすれば公開できます。
ビルドコマンドは不要です。フォルダ内のファイル構成を変えずにアップロードしてください。

## できること

### デッキ構築タブ
- 576枚のカードを 名前/テキスト検索・種類・色・レベル・収録弾・レアリティ で絞り込み
- 40枚以上・同名カード4枚まで（「デッキに何枚でも入れてよい」カードは例外）のルールに沿ってデッキを作成
- デッキはブラウザ内（localStorage）に保存され、次回起動時も残ります
- テキスト形式での書き出し・読み込みにも対応（バックアップや共有用）

### ソロプレイタブ（1人回し）

保存したデッキを選んで対戦開始。シャッフル・手札6枚・ガーディアン4枚を自動で配置します。

**盤面**
- カードは横1：縦1.4（104×146px）。裏向きは無地の紫の裏面です
- 表向きは左上にアイコン、右上にレベル（黒字の丸）、その左にマホウの魔力コスト（小さい○）、イジンは右下にパワー
- 上段＝山札｜戦場／中段＝墓地｜魔力ゾーン／下段＝手札｜操作ボタン
- 枠はゾーンごとに独立。**カードが0枚のときも枠の大きさは変わりません**
- 各段は下端を揃えているので、戦場の枠の下辺と山札の枠の下辺が一致します
- フェイズ表示の枠は山札の枠と左右の位置が揃い、その右にログ（最新4行）が並びます
- 戦場では左から ガーディアン → イジン → 表向きのハイケイ の順に並び、ハイケイは少し間隔を空けます
- 「寝ている」カードは右に90度倒れ、そのぶんの横幅を確保するので隣に被りません
- 盤面上では文字が選択されないので、ドラッグ中に青く反転しません
- ログは画面の中央あたりまでの幅で、その右側に ↩（一手戻す）／ターンエンド／終了が右詰めで並びます
- ログは**新しいものが上**に積まれ、既定では上から4行が見えています。スクロールすると下まで全履歴を遡れます（最新行は明るく表示）
- 「遊び方」ボタン（↩ の左）を押すと、この画面の全操作の説明が中央に開きます
- 多色のマリョク（RYマーブルストーン、ヒエロスガモス など）はアイコンの丸を中央で分割して両方の色を示し、カードテキストの背景も同じ2色で塗り分けます

**アニメーション**が付くのは次の操作です：山札クリックのドロー／ダブルクリックで墓地へ／山札から墓地へ／ボタン操作のマリョク配置／ボタン操作のイジン召喚／カードを寝かせる・起こす／カードが増減してゾーンが並び替わるときの整列。
着地点は**そのカードが実際に並ぶ位置**です。先に移動を確定して並べ替えてから、着地したカードの位置を実測して飛ばしているので、戦場のようにハイケイが右端へ再整列するゾーンでも、正しい最終位置に着地します。墓地へ向かうカードはフェードアウトして消えます。移動は `transform` で行うため、毎フレームのレイアウト計算が発生せず滑らかに動きます。

**操作は基本的にマウスで完結します**
| 操作 | 結果 |
|---|---|
| カードをワンタップ | カードの詳細を表示 |
| カードをダブルタップ | 墓地へ送る |
| カードをドラッグ | 別のゾーンへ移動 |
| 山札をワンタップ | 1枚ドロー |
| 山札をダブルタップ | 上から1枚を墓地へ |
| 墓地をタップ | 墓地の中身を一覧 |
| 墓地の一覧からドラッグ | 手札・魔力ゾーン・戦場へ移動（場に出すときは表／裏を確認） |

- ドラッグで戦場・魔力ゾーンへ運ぶと「表」「裏」を確認します。山札へ運ぶと「上」「下」を確認します
- ドラッグによる移動は効果による移動の扱いで、配置権・召喚権を消費しません
- 戦場の裏向きカード（ガーディアン）はルール上表を見てはいけないため、タップしてもカード情報は出さず「寝かせる／起こす」「表にする」だけのパネルが開きます。魔力ゾーンの裏向きカードは自分だけ確認できるので詳細が開きます
- 詳細画面に残しているボタンは、マウスでは代替できないものだけです（マホウの「使用」、戦場・魔力ゾーンのカードの「寝かせる／起こす」「表裏の反転」）

**メッセージ表示**
選択や確認のメッセージは画面中央に出て、周囲がやや暗くなります。選ぶべきカードだけが明るく浮き上がり、そのままクリックできます。メッセージが選択対象のゾーンに重なる場合は、左右には動かさず上下にずれて避けます。**暗い部分をクリックすると操作を取り消せます**（✕ボタンはありません）。条件を満たしていない操作をすると「○○条件を満たしていません」が中央に一瞬出て消えます。

**フェイズ進行（操作が必要なのはメインフェイズのみ）**
- スタートフェイズは全自動（戦場を起こし、各権利をリセット）
- ドロー段階では盤面が薄暗くなり、山札だけが光ります。山札をクリックするとドローしてメインフェイズへ進みます（この間も ↩／終了は押せます）
- 先攻1ターン目はドローせずメインフェイズへ進み、「先攻1ターン目のためドローをスキップします」が画面中央に一瞬表示されます
- **メインフェイズ中も山札クリックでドローできます**（カード効果によるドロー用）。フェイズが進むのはドローフェイズのドローだけです
- 「ターンエンド」で手番終了

**メインフェイズのボタン**
手札の右にカード大の角なし正方形ボタンが3つ。下に残り回数と増減ボタンがあります。こちらは権利を消費する正規の手順です。
- **マリョク配置**：「どちらで配置しますか？」→「表」「裏」。手札にマリョクが無いときは「表」が暗くなり押せません
- **イジン召喚**：条件を満たすイジンだけが光ります。該当が無ければボタンが暗くなります
- **バトル**：アタッカーを選ぶと寝かせられ、「攻撃」で確定

**遺業能力の注意表示**は、ルール通り「戦場から墓地に置かれたとき」だけ出ます（手札・魔力ゾーン・山札から墓地に置かれた場合は発動しないため表示しません）。

**バトルボタン**は、バトル権が無いとき、またはアタッカーに選べるイジンが戦場にいないときは押せません。

**自動化されないもの：** 各カード固有の効果（ルールテキストの内容）は自動判定されません。「発動できる」の条件判定も含め、効果の適用はご自身でルールテキストを読みながら上記の操作で反映してください。

## データについて

同梱の `cards-data.js` は、提供いただいた第1〜6弾のカードリスト（Excel）から自動生成しました。
元データにはカードの「種類」列が無かったため、パワー・レベル欄・ルールテキストの記載内容から
イジン / マホウ / ハイケイ / マリョク を自動推定しています。推定が難しいカードは、
まれに誤分類されている可能性があります。デッキ構築画面のカード詳細で種類が明らかにおかしい場合は、
実物のカードを見て判断してください（本アプリのソースコード `cards-data.js` 内の `type` の値を
直接書き換えることでも修正できます）。
